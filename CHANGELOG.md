## [Unreleased]

### Added

- Chrome extension for browser recording (`browser-recorder-extension/`)
  - Captures all 11 event types with Codegen-style selectors
  - iframe support via `all_frames: true`
  - Popup UI for start/stop/export
- `models/` package with new Pydantic models:
  - `UIEvent`, `UIEventType` (11 event types)
  - `SelectorCandidate` (role, label, placeholder, text, testid, css strategies)
  - `RecordingSession`, `SessionMetadata`, `VideoInfo`
- `playback/` package for session replay:
  - `SessionExecutor` - handles all 11 event types with coordinate fallback
  - `SelectorResolver` - priority-based selector resolution (Codegen-style)
  - `SafeReplayController` - network interception modes (live/warn/block/mock)
- `storage/` package with `SessionStore` for session management
- Codegen-style selector generator (`js/selector-generator.js`)
- New CLI commands for session-based workflow:
  - `replay-session` - replay with multi-selector resolution
  - `import-session` - import Chrome extension exports
  - `convert-session` - convert session to ActionDefinition via LLM
  - `list-sessions` - list all recording sessions
- Safe replay mode (`--safe` flag) with configurable modes
- Prompt template `convert_session.yaml` for new session format
- update claude subagents from ai-agent-teacher

### Changed

- Playback uses priority-based selector resolution (role > label > placeholder > text > testid > css)
- Session storage now in `sessions/` directory (Chrome extension exports)
- split models into modules, add playback/storage packages, update tooling

### Fixed

- Navigation deduplication now checks event type (was comparing URLs across all event types)
- Duplicate right-click events in Chrome extension (removed from click handler)
